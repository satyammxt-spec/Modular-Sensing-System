# Modular-Sensing-System
Smart sensing architecture exploring GNSS and IMU sensor fusion, indigenous components, and a FastAPI-based web demonstration for the Smart India Hackathon.
* Code Assembly: Contributing to code integration and ongoing technical development within the project team.
* Pricing & Budgeting: Researching component costs and preparing budget estimates for project planning.
* Technical Presentations: Developing PowerPoint presentations to communicate the project concept, architecture, and technical requirements.
* Sponsorship & Outreach: Supporting sponsorship research and outreach to identify potential funding and project resources.
* System Architecture: Exploring modular electronics, embedded processing, and sensor-fusion concepts as part of the ongoing design process.
* Project Status: Currently in development, with implementation and validation activities in progress.
